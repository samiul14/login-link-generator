# 🚀 Login Link Generator & Preview App

Developed by **samiul14** (Wsamiul)

---

## 📚 Educational Purpose Notice
This project is created **strictly for educational, learning, and web development practice purposes** (to understand Python socket programming, HTTP servers, and front-end HTML/CSS design in a mobile Linux environment like Termux).

---

## 📱 Features
* **Link Generator:** Generate custom preview links dynamically from website names.
* **Original Look Simulation:** Renders a clean, simulated login interface (e.g., Facebook style) for learning UI/UX design concepts.
* **Termux Friendly:** Runs completely on pure Python standard libraries without requiring heavy external dependencies.
* **Developer Branding:** Integrated with developer credentials (`samiul14` / `Wsamiul`).

---

## 🛠️ Requirements
* **Python 3.x** (Termux built-in or standard system Python)
* **No external pip packages required** (uses built-in standard modules: `http.server`, `socketserver`, `urllib.parse`).
